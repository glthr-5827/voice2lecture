# Voice2Lecture

Офлайн-приложение для превращения аудио и голосовых записей в конспект.
Работает **без интернета**, **без нейросетей** и **без API-ключей**.

## Скачать

Перейдите в раздел [Releases](../../releases/latest) и скачайте
`Voice2Lecture.exe` для Windows.

## Как пользоваться

1. Запустите `Voice2Lecture.exe` (двойной клик).
2. В окне приложения нажмите **«Загрузить»** — модель Vosk уже встроена в `.exe`.
3. Нажмите **«Открыть аудио»** и выберите файл: wav, mp3, m4a, ogg, flac, opus.
4. Дождитесь распознавания (зависит от длины файла).
5. Нажмите **«Структурировать»** — получите конспект.
6. Сохраните как `.md` или скопируйте в буфер.

## Системные требования

- Windows 10/11 (64-bit)
- 4 GB RAM
- 200 MB свободного места

## Первый запуск

Windows может показать предупреждение SmartScreen
(«Windows protected your PC»). Это нормально для приложений без
цифровой подписи. Нажмите **«More info» → «Run anyway»**.
